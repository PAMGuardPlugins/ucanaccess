# ucanaccess
PAMGuard databse interface to MS Access files using ucanaccess

This plugin allows PAMGuard to work with Microsoft Access databases using the
[UCanAccess](https://github.com/spannm/ucanaccess) pure Java bridge into Microsoft Access databases. 

It is compatible with PAMGuard versions 2.3.0 or higher. 

Currently this module is throwing a lot of errors and needs some significant debugging before it can be usefully deployed. 

To use the plugin, download the latest jar file and drop it into your pamguard plugins folder (generally 
C:/Program Files/Pamguard/plugins on Windows devices). The interface will then appear in the list of available 
database systems in the [PAMGuard database system](https://www.pamguard.org/olhelp/utilities/generalDatabaseHelp/docs/database_database.html).
